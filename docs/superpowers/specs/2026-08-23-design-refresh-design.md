## 1. デザインコンセプト

明るくかわいい「表の顔」（パステル面）と、正体隠匿ゲームらしい謎めいた「裏の顔」（ダーク面）を**場所で使い分ける**。全面カラフル・全面ダークのどちらにも振り切らず、メリハリで安っぽさを回避する。

- パステル面: トップのヒーロー、魅力訴求、使い方、FAQ、フォームなどサイトの大部分
- ダーク面: 役職紹介・ゲームの緊張感を伝えるセクションに限定（rule.html の役職パート、トップの世界観訴求1セクション）
- モーション言語: 「弾む・にじむ・ふわっと浮く」で全ページ統一。鋭いスライドや硬い動きは使わない
- 装飾は引き算: マスコットとコピー1行を主役に、背景・UI装飾を増やさない（Oink Games型）

### 運用ルール

- 本文テキストのコントラスト比 4.5:1 以上を必須とする。パステル（primary/secondary）は背景・装飾専用で、文字色には使わない。文字は必ず `ink` / `accent`（ライト面）、`dark-text` / 白（ダーク面）
- 色だけに意味を持たせない（役職・状態はアイコン/ラベル併用）
- 全面に薄い CSS グレインテクスチャ（SVG feTurbulence または軽量ノイズ画像）を重ね、ベタ塗りの安っぽさを回避する

## 6. モーション・3D

### three.js（ユーザー指定・見せ場担当）

- **用途**: `index.html` ヒーローの3Dシーン。パステル調の小物（仮面・虫眼鏡・カード）がふわふわ浮遊し、マウス移動（PC）/スクロール（モバイル）で視差が付くパララックス演出
- **実装ガード**（モバイル主体のため必須）:
  - `three` は dynamic import で遅延読み込みし、LCP（ヒーローのコピー・CTA表示）をブロックしない
  - `devicePixelRatio` は最大2にキャップ
  - IntersectionObserver で画面外に出たらレンダリングループを停止
  - `prefers-reduced-motion` または WebGL 非対応時は3Dを初期化せず、フォールバック静止画（アセット#5）を表示
  - 3Dキャンバスは index.html ヒーローの1箇所のみ。他ページには持ち込まない

### GSAP（スクロール演出担当）

- `gsap` core ＋ ScrollTrigger を npm 導入（2025年4月以降、商用含め全プラグイン無料）
- 使用箇所を限定: ①ヒーローのコピー文字リビール＋マスコット登場タイムライン、②各セクションのスクロール連動パララックス（背景と前景の速度差）、③rule.html のライト面→ダーク面転換演出
- 単純なフェードイン/スライドインは GSAP を使わず IntersectionObserver＋CSSトランジション（依存ゼロ）で実装

### マイクロインタラクション

- ボタン: タップ時のスクワッシュ&ストレッチ（軽い縮小→戻る押し込み感）、ホバー時 `scale(1.03)` 程度の微膨張
- カード: ふわっと浮き上がり（`translateY(-4px)`＋シャドウ）
- CTA: シャインエフェクト1種のみ。パルス・バッジ等を重ねない
- アニメーション対象プロパティは `transform` / `opacity` に限定

### アクセシビリティ（no-motion-first）

- `prefers-reduced-motion: reduce` 時: three.js・GSAP を初期化せず、CSSアニメーションも最小限のフェードのみ残す。設計段階からこの分岐を組み込む（後付けにしない）
- タップ領域 44px 以上、ボタン間隔 8px 以上

## 9. 実装フェーズの順序（概要）

詳細は実装計画（writing-plans）で定義するが、大枠は以下の順とする。

1. **アセット制作フェーズ**: Codex image_gen スキルで §4 のアセット一覧を全て生成・配置
2. **基盤フェーズ**: Tailwind `@theme` トークン、フォント、共通パーシャル（ヘッダー/フッター/ボトムナビ/フローティングCTA）
3. **ページ実装フェーズ**: index → rule → Instructions/opinion → form/line → 記事/カラオケ
4. **モーションフェーズ**: three.js ヒーロー、GSAP演出、マイクロインタラクション
5. **検証フェーズ**: コントラスト・reduced-motion・実機モバイル・既存テスト・リダイレクト確認
